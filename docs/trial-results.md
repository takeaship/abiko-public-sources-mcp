# 市民の14質問を使った試用

2026-11-15 JST。14問を独立したサブエージェントで試し、現行5ツールを正規のstdio MCP接続で475回呼び出した。外部Web検索・直接HTTPによる回答の補完は行っていない。

## 得られた結果

進行役の集約判定は「回答可」4問、「一部」10問。主たる生活上の問いに一般案内を返せたかの判定であり、正解率・網羅率ではない。各問1回の探索で、独立した参照正解一式を使った評価は行っていない。

| テーマ | 判定 | 到達した範囲と残る課題 |
|---|---|---|
| 通勤・交通 | 一部 | 公共交通の計画・変更案へ到達。自転車や地区別の十分性は未確認 |
| 駅前の変化 | 一部 | 決定・実施・予定を区別。最寄り駅と出口が不明 |
| 住まい | 回答可 | 持ち家向けと賃貸・単身者に関係する制度・相談先を区別 |
| 買い物・飲食 | 一部 | 市民の直接意見へ到達。古い意見と直近の声を区別 |
| 仕事・働き方 | 一部 | 就職・創業の相談等へ到達。在宅勤務向け支援の有無は未確定 |
| 趣味・余暇 | 一部 | 施設の利用条件へ到達。利用時間拡大の議論は未確認 |
| 地域のつながり | 回答可 | 個人・単発で参加する活動や相談先を具体化 |
| 手続の不便 | 一部 | オンライン申請・来庁・受付停止を区別。希望手続が不明 |
| 身近な安全 | 一部 | 要望先と公開回答例へ到達。個別地点の工事完了は未確認 |
| 防災・住む場所 | 一部 | 対策と課題を整理。地区別リスク・十分性は未確認 |
| 生活費 | 回答可 | 実施中・終了済みの支援を区別し、相談先を案内 |
| 家族のケア | 回答可 | 相談先に加え、審議会での相談体制の議論へ到達 |
| 税金・公共施設 | 一部 | 方針・費用・個別事例へ到達。全施設の最新判断は未照合 |
| 意見の届き方 | 一部 | 参加経路と審議での意見の扱いへ到達。施策変更・実施との因果は未確認 |

「回答可」も個人の制度適用、予約残数、最新性や全資料の網羅を保証しない。14問の結果を、子育てテーマの4受入シナリオの合格判定には置き換えない。

## 試用条件と観察

各問は独立した空の保存先で開始し、既存取得データを取り込んでいない。最大3担当を動かし、MCP呼出しは共通ロックで1件ずつ実行した。1呼出しごとに接続し直しているため、持続接続の通常利用とは条件が異なる。

1問あたり28〜38呼出し、初回要求から最終応答まで約6〜10分。全14問の呼出し窓は50分41秒。ツール別件数はリンク発見153、取得118、検索24、本文参照165、PDF画像15。

MCPエラー2件は対象外URLの拒否。取得処理に進んだ269回のうち、成功フラグ267回・失敗2回。成功フラグのうち4回は空本文であり、本文を読めた件数には数えない。

主な課題は、毎回の資料探索、取得済み本文だけの検索、議会検索システムから本文への到達、PDFの抽出失敗・文字化け・画像、地区等が不明な質問への絞り込みだった。

選定した代表箇所は保存原文と照合したが、全回答の全主張や個別適用条件を独立検証したものではない。このページは試用の集計で、取得済み本文・PDF・回答全文・呼出しログは含まない。
